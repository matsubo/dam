## 背景

MLIT 川の防災情報 / 水文水質データベースから直接プログラムでデータ取得することは利用規約上認められていない一方、河川情報センターが運営する **水防災オープンデータ提供サービス** が公式に再配布チャネルとして機能していることを確認した
(<https://www.river.or.jp/koeki/opendata/index.html>)。

当サービスは雨量約 2300 局・水位約 2000 局・**ダム諸量約 150 局**・積雪約
140 局・水質約 230 局・海岸約 100 局を配信しており、リアルタイム/準リア
ルタイム/蓄積一括の 3 方式に対応する旨が記載されている。

**dam.teraren.com (Dam Data Platform)** はオープンソースの日本ダム貯水量プ
ラットフォームで、現在 45 ダム (1.6%) の実観測値しか持たない。残り
2,704 ダムは合成シード値表示にとどまり、災害予測・水不足アラートの実用に
耐えない状態。MLIT 管轄ダムの提供サービス契約により、150 ダム分の
real-time 5 分間隔データを取り込めば、coverage を 1.6% → 約 7% に引き上
げられる。

## 想定される返信パターンと次のアクション

| パターン | 次のアクション |
|---|---|
| 料金表 + 申込書 PDF 添付 | 申込書記入 → 契約締結 → 接続情報取得 → kasenbosai 風 XML パーサーで実装 (`packages/adapters/kasenbosai/` の既存コードを流用) |
| 個人契約不可 / 法人限定 | (a) 法人設立コストと比較 (b) 別の研究機関と共同で申し込めるか調査 (c) 諦めて Weathernews 集約サイトに切り替え |
| 非営利割引あり | 同上 (a) 即契約 |
| 利用約款で二次配布禁止 | 当サイト内表示のみで API 提供取り下げ。または「未認証ユーザは表示しない」ゲート実装 |
| 返信なし (2 週間) | 電話 (03-3239-8447) でフォローアップ |

## 既存実装 (契約取得後の流れ)

接続情報取得後、以下の既存リソースを活用:

```
packages/adapters/kasenbosai/  ← XML パーサー + adapter プレースホルダー既存
apps/worker/src/tasks/         ← 既存 4 ソースの実装パターン (tokyo / jwa-junpo / aitoyo / jwa-chikugo / kanagawa-dam) を参考
```

新規実装の要点:
1. `apps/worker/src/tasks/ingest_mlit_haisin.ts` 新設
   - 認証 (取得した API キーで HTTP リクエスト)
   - 配信フォーマットに合わせたパーサー (既存 kasenbosai/parser.ts を改修可能性大)
   - 150 ダムの dam_id 紐付け (NAME_MAP or 観測所コードベース)
2. `source_priorities` に `mlit-haisin` 優先度 350 (最高) で登録
3. crontab `*/5 * * * * ingest:mlit-haisin` (5 分間隔)
4. SOURCE_DETAILS にエントリ追加
