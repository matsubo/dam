# One reading rule and effective capacity for every 貯水率

Every view of a dam at a moment (dam page, 平年比, map, 水系, 全国) uses the same reading: the observation chosen by one rule in the database. That rule prefers a fresh trusted source, then takes the newest observation that carries a value, then breaks ties by source priority and source id. Every 貯水率 divides by effective capacity, for a single dam, a 水系 or the whole country.

Before this, five separate pick rules existed. #121–#123 fixed the same tie-break three times. 平年比 could use a different source than the 貯水量 shown above it, and 全国貯水率 divided by the static 有効貯水容量 while 水系 used effective capacity. Accepting the change shifts the published national figure and some map and 平年比 values; that is intended, because consistency between views was judged worth more than continuity of the old numbers. Per-view rules optimised for one screen were rejected for the same reason.
